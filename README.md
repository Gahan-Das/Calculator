<h1>🧮 Calculator (CustomTkinter)</h1>

A GUI-based calculator built using Python and CustomTkinter.
This project focuses on implementing a functional calculator with both button-based and keyboard-based input.

<h3>✨ Features<h3></h3>
<ul>
<li>Basic arithmetic operators:</li>
<ul>
<li>Addition (+)</li>

<li>Subtraction (-)</li>

<li>Multiplication (*)</li>

<li>Division (/)</li>
</ul>
<li>Advanced operations:</li>
<ul>
<li>Power</li>

<li>Left and Right Parentheses ( )</li>
</ul>
<li>Mathematical constants:</li>
<ul>
<li>π (pi)</li>

<li>e (Euler’s number)</li>
</ul>
<li>Keyboard input support for faster and more natural usage</li>

<li>Modern and minimal UI using CustomTkinter</li>
</ul>
🛠️ Technologies Used
<ul>
<li>Python</li>

<li>CustomTkinter</li>
</ul>
