<h1>🧮 Calculator (CustomTkinter)</h1>

A GUI-based calculator built using Python and CustomTkinter.
This project focuses on implementing a functional calculator with both button-based and keyboard-based input.

<h3>✨ Features<h3></h3>
<ul>
<li><h6>Basic arithmetic operators:</h6></li>
<ul>
<li>Addition (+)</li>

<li>Subtraction (-)</li>

<li>Multiplication (*)</li>

<li>Division (/)</li>
</ul>
<li><h6>Advanced operations:</h6></li>
<ul>
<li>Power</li>

<li>Left and Right Parentheses ( )</li>
</ul>
<li><h6>Mathematical constants:</h6></li>
<ul>
<li>π (pi)</li>

<li>e (Euler’s number)</li>
</ul>
<li><h6>Keyboard input support for faster and more natural usage</h6></li>

<li><h6>Modern and minimal UI using CustomTkinter</h6></li>
</ul>
